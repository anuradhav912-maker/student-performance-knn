# Student Performance Prediction Using KNN

A machine learning project that predicts student final grades using the K-Nearest Neighbors (KNN) Regression algorithm.

## Project Highlights

- Dataset: UCI Student Performance Dataset
- Algorithm: K-Nearest Neighbors (KNN)
- Problem Type: Regression
- Features: Study Time, Failures, Absences
- Target: Final Grade
- Evaluation: MAE and RMSE

## Tools

Python | Pandas | NumPy | Matplotlib | Seaborn | Scikit-learn | Google Colab

## Project Files

- `Student_Performance_KNN.ipynb` — Complete project notebook

## Result

The trained KNN model predicts the final grade of a student based on the selected academic features.
